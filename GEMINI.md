# Project Instructions

## Documentation and Progress Tracking
- Always update `SPECIFICATION.md` and `ROADMAP.md` when a new feature is implemented or an architectural change is made.
- Maintain consistency between the implementation and the documented specifications.

## Configuration File Guidelines
- When modifying `sample_concept/config.json` or any other concept configuration files:
  - **Do NOT** change the `texture` paths for `player`, `boss`, or `bullets` unless explicitly instructed.
  - **Do NOT** change the `settings` for `player`, `boss`, or `screen` (resolution) unless explicitly instructed.
  - Focus modifications only on the `timeline` or the specific logic requested.
  - This ensures that the samples remain functional with existing assets and layout.
